# ECHO - AI Speech Analytics & Delivery Diagnostics 🎙️⚡

**ECHO** is an AI-powered contrastive speech analytics platform featuring temporal flaw grounding, acoustic measurements against standard oratorical baselines, actionable vocal drills, and an intelligent multi-lingual speech assistant.

---

## 🌟 Key Features

- **⚡ 100% Client-Side Web Audio DSP**: Real-time signal processing and pitch / cadence extraction without cloud dependencies.
- **🎯 Temporal Flaw Grounding**: Pinpoints fast speech, hesitation, awkward pauses, and volume irregularities directly on the interactive waveform and timeline.
- **📊 Metric Breakdowns**: Contrastive scoring across Pacing (WPM), Pitch Modulation, Articulation Clarity, and Pausing ratios.
- **🤖 ECHO AI Speech Coach**: Context-aware assistant supporting questions in **Hindi, Hinglish, and English**.
- **🎙️ Live Recording Studio & Preset Benchmarks**: Record directly in the browser or load curated speech samples.
- **🌐 Interactive Transcript & Translation**: Synchronized playback head with dual-language translation support.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0+ / v20.0.0+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/patelanshika8084-dot/ECHO.git
cd ECHO

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Building for Production

```bash
npm run build
npm run preview
```
